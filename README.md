# ZomATON · Genesis №0

Один фрактальный корень, из которого исследователь сам открывает вложенные миры. Выбираешь область, приближаешься, видишь заново рассчитанные структуры и выбираешь следующую точку уже внутри. Адрес сохраняет всю цепочку выборов от Genesis, чтобы исследователь или другой человек смог пройти тот же маршрут.

## Попробовать

Откройте `explorer/ZomATON_Geometry_Offline.html` в браузере. Он работает без сети, кошелька и скачивания моделей. Клик по полю пересчитывает геометрию того же мира, а не увеличивает прежнюю картинку. Переходите снова внутри результата; сохранённый адрес открывает те же шаги.

Сквозные проверки:

```sh
cd explorer
node verify.cjs
node verify-ui.cjs
```

В двух последовательных спусках новый кадр побайтно совпал с соответствующей областью поля, независимо пересчитанного с вчетверо большей линейной детализацией; обычное растягивание прежнего кадра дало другое изображение. В обоих проверенных переходах внутри одного старого пикселя обнаружились разные орбиты. Контрольные суммы и координаты в `explorer/geometry-evidence.json`. Это математический 2D-прототип с ограниченной глубиной, не обещание бесконечной детализации и не генерация художественной сцены в произвольной точке.

## Что значит NFT

Genesis №0 задуман как один коллекционный корень в сети TON. Просто исследовать мир можно без токенов. Открытие внутренней точки само по себе не минтит NFT, не расходует тираж корней и не обещает дохода.

`ton/` содержит локально проверенный кандидат TON-контракта. Для тестов: `cd ton && npm ci && npm test`. Нет стороннего аудита, testnet/mainnet-деплоя, продажи или подтверждённого дохода. Окончательный выпуск должен включать проверяемые метаданные и работающую демоверсию.

Сторонние исходники TON поставляются с их лицензией в `ton/upstream/LICENSE`. Публичная видимость не означает, что остальные материалы распространяются под той же лицензией.

## Макро- и микромиры

[Демо двух спусков](https://zomaton-genesis.goofy-eel-8827.chatgpt.site/worlds/) или `worlds/ZomATON_Macro_Micro.html` офлайн. Первая произвольная точка меняет крупный рельеф, вторая строит мелкие структуры из области первого мира. Адрес сохраняет оба выбора. Тесты: `node worlds/engine/verify.cjs`, `node worlds/qa/acceptance.cjs` и `node --test worlds/viewer/viewer.test.cjs`.

Это ранний процедурный режим, не художественный релиз и не коллекция выпущенных NFT. Исследование само по себе не инициирует транзакции.

## Живые миры

[Открыть живые миры](https://zomaton-genesis.goofy-eel-8827.chatgpt.site/living/) или `living/ZomATON_Living_Offline.html` офлайн. Версия адреса `zlw1` сохраняет путь между биомами. Посетитель может исследовать дальше двух переходов; рельеф наследуется от выбранной области, движок добавляет геометрию и рисует флору и подвижную фауну. Старые демо сохранены.

Локальные проверки: `node living/engine/verify.cjs`, `node --test living/viewer/viewer.test.cjs`. Проверены 24 последовательных шага движка и 12 кликов в тестовом интерфейсе, не физический Android. Нет NFT-минта или оплат.
